# 数据、验证与评估

## 本章目标

- 采用“实际问题—既有方法的难点—技术机制—适用边界”的叙事顺序，避免核心概念直接从定义起笔。
- 强调数据质量对模型效果的决定性作用。
- 理解训练集、验证集、测试集和线上评估的差异。
- 掌握常见指标和评估陷阱。

## 建议结构

1. 数据决定模型上限
   - 噪声标签。
   - 数据偏差。
   - 分布漂移。
   - 长尾样本。
2. 数据切分
   - 训练集用于学习参数。
   - 验证集用于调参和选择模型。
   - 测试集用于最终评估。
   - 数据泄漏的危害。
   - 回归集和线上评估的作用。
   - K-fold 交叉验证和分层交叉验证。
3. 评估指标
   - Accuracy、Precision、Recall、F1。
   - 混淆矩阵：TP、FP、FN、TN。
   - 用垃圾邮件检测例子计算指标。
   - F1 的调和平均、等价公式和低值惩罚直觉。
   - F1 不等于 Accuracy、不使用 TN，并依赖正类定义与分类阈值。
   - F-beta 对 Precision 与 Recall 的非对称权衡。
   - 多分类中的 per-class、macro、micro 和 weighted F1。
   - AUC。
   - 类别不平衡下的采样、类别权重和 Focal Loss。
   - 回归任务中的 MAE、MSE。
   - 用房价预测例子计算 MAE 和 MSE。
   - 生成任务中的人工评估和偏好评估。
   - LLM-as-judge、任务成功率、BLEU/ROUGE 的边界。
   - A/B 测试和影子测试。
4. 数据增强与长尾覆盖
   - 图像增强和文本增强。
   - 数据增强不是造假，而是覆盖合理变化。
   - 高风险长尾样本需要单独覆盖。
5. 错误分析
   - 按场景、用户、长度、类别分桶。
   - 找到高频错误和高损害错误。
   - 从指标回到样本。
   - 错误案例库和回归集。
6. 数据治理
   - 数据标注规范。
   - 内部标注、众包标注、半自动标注和主动学习。
   - 去重、清洗与版本管理。
   - 隐私、安全和版权边界。
   - 数据版本、处理流水线和权限审查。
   - 数据漂移和概念漂移监控。

## 实践任务

- 为一个分类任务选择合适指标。
- 设计一个错误分析表格。
- 列出三种可能的数据泄漏方式。
- 手动构造一个二分类小样本，计算混淆矩阵、Precision、Recall 和 F1，并观察阈值变化。
- 用 3 条回归样本计算 MAE 和 MSE。

## 本章产出

读者应能理解模型效果不是单个分数，而是数据、指标和场景共同决定的结果。
